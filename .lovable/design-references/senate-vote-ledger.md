# Senate Vote Ledger

Canonical visual reference for the in-game Politics > Votes view.

Use when the user asks for the **Senate Vote Ledger** look.

Key traits:
- Restrained Roman civic-record presentation
- Ivory voting surface with fine bronze rules
- Compact, information-dense horizontal layout
- Dark, readable body copy
- Large serif vote totals with small uppercase stance labels
- Yea in blue, Nay in verdigris, Abstain in a quiet neutral
- Minimal decoration; formal ledger/tabulation character
